How should we polish Artemisa?

All three keep the current color palette and feel — they differ in scope

A

Light Touch — Fix the UX bugs

Target the most painful issues only: add a hamburger menu for mobile nav, make the search bar always visible, add active link highlighting in the navbar, and fix the dark mode toggle alignment. Minimal CSS changes, fast to ship.

Pros

  • Lowest risk
  • Fast to implement

Cons

  • Doesn't address inconsistencies
  • Mobile sidebar still awkward
B

Component Uplift — Consistent system ⭐ Recommended

Fix all UX bugs + establish a consistent design language: hamburger nav drawer, always-visible search, active states, improved sidebar/filter panel (collapsible on mobile), better typography hierarchy, and cleaned-up color usage across all pages.

Pros

  • Feels cohesive end-to-end
  • Mobile experience greatly improved
  • Extensible for future pages

Cons

  • More changes to review
C

Full Polish — Everything + visual refinements

All of Option B plus: animated page transitions, subtle glassmorphism on the navbar, refined card hover states, better book carousel on mobile (swipe-friendly), and a tighter spacing scale across all components.

Pros

  • Most impressive result
  • Premium feel

Cons

  • Most changes — higher review burden
  • Animations can feel heavy if overdone
