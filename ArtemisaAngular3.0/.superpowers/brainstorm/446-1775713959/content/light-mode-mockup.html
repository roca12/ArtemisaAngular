Binary Search
BúsquedasO(log n)

Algoritmo de búsqueda eficiente sobre arreglos ordenados. Divide el espacio de búsqueda a la mitad en cada paso.

Java
int binarySearch(int[] arr, int target) {
  while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (arr[mid] == target) return mid;
  }
  return -1;
}
